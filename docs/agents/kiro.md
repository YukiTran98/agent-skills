# Kiro — hướng dẫn cài skill

## Install path

| Scope | Path |
|---|---|
| Local (repo) | `.kiro/steering/<skill-name>.md` |
| Global | `~/.kiro/steering/<skill-name>.md` |

## Cài skill

```bash
skh install --agent kiro
# hoặc cụ thể hơn:
skh install --agent kiro --group GENERAL --global
```

## Xem skills đã cài

```bash
skh list --agent kiro --installed
```
